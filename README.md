# Proxy Play

A simple browser-based game portal with:
- a website launcher input
- built-in demo games
- a clean modern layout

## Open it

https://leodeliberato-eng.github.io/proxy-game-website/

## Local preview

Open `index.html` directly in your browser, or run a tiny local server:

```bash
python3 -m http.server 8000
```

Then go to:

http://localhost:8000
